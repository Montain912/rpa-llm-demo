## 启动与端口

在项目目录运行 `python -B main.py`，访问 <http://127.0.0.1:5010>。
页面和任务 API 使用 5010，远程桌面 WebSocket 代理使用 6081，避免占用已有的 5000/6080 服务。
前端 API 和状态连接跟随当前页面地址，桌面代理端口由服务返回。

可用 `RPA_HTTP_PORT`、`RPA_WS_PORT` 环境变量覆盖默认端口。
若直接使用 Uvicorn，需显式指定：`uvicorn main:app --host 0.0.0.0 --port 5010`。
旧 Flask 入口 `app.py` 也默认使用 5010，两个入口不要同时启动。

### 定位修正说明

同一目标连续修正坐标时，若局部画面像素完全未变且新坐标仍在原局部范围内，
保持局部截图的原点和尺寸，避免局部坐标系随候选坐标移动。
目标变化、画面变化、分辨率变化或候选移出原范围时重新取图。
只复用截图范围，不复用验收结果；每次仍独立定位并检查几何边界。
此修正已通过本地回归测试，实际业务成功率仍待完整服务复测。

## 文本与中文输入

- 账号、密码在首次输入和纠错输入前，使用新截图独立确认对应字段焦点。
  整页文字选中、仅悬停或已有文字不算焦点证据；未确认时不发送全选、删除和字段文字。
  登录宏失败保留原阶段，未发送文字不消耗纠错输入次数。该检查不替代输入后的内容验收。

- ASCII 文本通过 VNC 逐键输入，不使用剪贴板。
- URL、邮箱和数字字段会把全角字符规范为半角并移除空白；密码、用户名、命令、代码和普通文本保持原值。
- 非 ASCII 文本（中文、emoji 等）只支持与 RPA 进程共享同一个 Windows 交互桌面的回环 VNC。确认满足这个条件后，启动服务前设置：

```powershell
$env:RPA_LOCAL_SENDINPUT = "1"
```

该开关默认关闭。若 `localhost` 实际是 SSH/Docker 转发、独立 VNC 会话或远程主机，请勿启用；当前 `vncdotool` 通道无法可靠保证这些场景的 Unicode 输入，Agent 会明确报错并停止重复输入。
